# 原版动作感稳定对比版（仅视频）

用途：本文件保留 `动作.txt` 的七段动作节奏、表情和主要动作描述，仅补充已验证必须有的稳定性约束。它是视频对比文件，不重新生成母图；请使用同一组已确认、已规范化的清醒母图 `@long` 和睡姿母图 `@sleep`，以便和原版公平比较。

全局稳定性补充（适用于以下全部动作，不取代各动作的可爱表现）

- 固定 16:9 画布、固定机位、固定焦距。角色的头部、躯干和四肢真实比例不能改变；水平中心与最低接地点基线稳定。不得以推拉镜头、镜头跟随、缩放、自动重新构图、裁切或漂移来完成动作。
- 每段首帧和尾帧是硬约束，必须准确回到该段绑定的 `@long` 或 `@sleep`：身份、脸部、主毛色、辨识性花纹、身体大小、水平位置、地面基线和姿势一致。中间动作结束后必须留出自然静止收尾，不能带着运动速度切到循环。
- 严格保留同一只狗的脸型、耳朵、口鼻、主毛色、显著花纹及左右归属。快速动作中仅允许毛发末端或极小斑纹短暂轻微波动；不得换脸、换毛色、花纹镜像/跨分区移动、增加肢体或尾巴。
- 背景始终为均匀纯绿色 `#00E676`，无纹理、无渐变、无地面阴影、无反光、无道具。均匀正面柔光。输出 480p、24 fps、无音轨、无背景音乐、无音效、无文字、无水印。
- 身体和尾巴始终完整可见。动作需要空间时缩小动作幅度，不缩小或放大角色本体；不得出现悬空、基线跳变或画面边缘裁切。
