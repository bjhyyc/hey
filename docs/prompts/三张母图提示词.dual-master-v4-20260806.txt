PetPack 图片与视频生成提示词（双母图混合版 V4）

适用模型
- 图片：Seedream 5.0 Pro
- 视频：Seedance 2.0，480p，24 fps，无音频；生成后由本地后处理统一输出为 1280×720

版本原则
- 保留当前版本已经验证有效的固定画布、固定机位、固定角色尺度、固定基线和纯色绿幕约束。
- 动作可以自然、有表现力，但个体外观还原优先级高于动作幅度；当二者冲突时，应减小动作幅度，不得牺牲脸部、花色、身体比例或毛发特征。
- 两张经用户确认的清醒母图共同定义宠物身份，但视频仍使用 Seedance 2.0 现有首尾帧模式；每次视频请求只传入该动作标明的首帧和尾帧，不声称能在首尾帧模式中同时附加多张身份参考图。
- 运动中优先保持身份、主花色、身体结构和连续性，允许毛发细节或很小斑纹出现不影响辨认的轻微短暂波动；所有动作的首帧和尾帧必须准确回到对应的已确认母图。

资源与变量约定
- @photo1、@photo2：用户必须上传的同一只宠物的两张不同正面全身实拍。两张都必须正面、完整、清晰，不能用同一文件、连拍近似重复图或 45°照片替代；它们共同负责锁定正脸、胸口、四肢、正面花色和真实身体比例。
- @photo3：用户必须上传的一张左前或右前约 45°全身实拍，用于补充一侧肩部、躯干、前后腿、背部和尾巴花色。
- @photo4：可选的另一张 45°全身实拍，优先选择与 @photo3 相反的一侧；用户只提供一张 45°照时不得阻止生成，也不得要求额外上传。
- @front：根据全部合格实拍照片生成、由用户确认的正面清醒身份母图。
- @side：根据全部合格实拍照片并继承 @front 的同一角色设计生成、由用户确认的单侧约 45° 清醒身份母图；方向选择真实照片信息更完整的一侧。该母图用于补充一侧身体、四肢、背部和尾巴的身份与花色信息，不要求展示七个动作不会完整露出的纯侧面。
- @sleep：系统在用户一次确认 @front 与 @side 后，自动同时参考这两张已确认母图生成并通过校验的睡姿母图。
- {{pet_type}}：必须由服务端根据用户选择替换为“狗”或“猫”，不得让模型自行猜测物种。
- @front、@side 和 @sleep 必须使用相同的 16:9 画布、固定机位、解剖尺度、水平中心和地面基线。侧面姿态允许外接框宽度自然变化，但不得放大角色填满画面。

母图生成与确认规则
- 系统先生成 @front，再以全部实拍和 @front 生成 @side；两张完成并通过一致性校验后，在同一页面并排展示，用户只需一次“确认这组形象”。
- @front 与 @side 各自提供“单独再生成”，重生成其中一张不应连带消耗另一张。建议每张允许用户主动再生成 2 次，即每个位置最多获得 3 个候选；因此一单最多增加 4 次用户主动图片生成，视频费用不变。
- 系统质量校验未通过而触发的内部重生成不占用用户的 2 次主动机会，也不得要求用户加钱。达到产品内部异常阈值仍无法得到合格母图时，转人工处理或退款，不把未通过的母图交给用户确认。
- 用户替换任意一张后，两张都重新执行同一角色、花色方向、解剖尺度、水平中心和地面基线校验；只有当前 @front 与 @side 同时合格时，“确认这组形象”才可用。

个体外观与花色锁定规范
- @photo1～@photo4 必须先逐张提取外观证据，再按身体分区和拍摄方向合并，不能把多张照片的毛色或花纹简单平均、混合成一只“相似宠物”。
- 外观证据至少分为：额头与眼周、口鼻、左耳、右耳、颈部与胸口、左前腿与爪、右前腿与爪、躯干左侧、躯干右侧、背部、左后腿与爪、右后腿与爪、尾巴。每个可见分区记录基础毛色、斑纹数量、形状、边界、相对身体地标的位置和左右侧归属。
- 严格保留真实宠物的品种特征和个体特征，尤其是头型、口鼻长短、耳朵形状与垂落方向、眼距、鼻色、头身比例、四肢长短、尾巴形态、毛发长短、卷曲度、蓬松度，以及面部和身体花色。
- 严格保留左右不对称。左侧特征只能留在左侧，右侧特征只能留在右侧；不得镜像、对称化、美化、简化、移动、放大、缩小、合并或删除斑纹，也不得把一侧斑纹复制到另一侧。
- 多张照片同一分区信息不一致时，以该分区更清晰、角度更正、遮挡更少的一张为准；若仍无法判断，则不得猜测成新的辨识性花纹。照片中没有记录到的隐藏区域只能连续延伸相邻的基础毛色，不能补造斑块或宣称已还原。
- 卡通化只允许改变渲染材质和细节表现，不得改变花色拓扑。花色拓扑是指每块斑纹的数量、所属身体分区、相对身体地标的位置、轮廓关系和左右方向。
- @front 与 @side 经用户一次确认后共同成为不可变的角色身份母本。用户可以分别重生成其中一张；一旦任一张被替换，系统必须重新执行双母图一致性校验，只有两张同时通过后才允许确认并生成 @sleep。
- @sleep 及七个视频必须继承两张已确认母图共同定义的脸部、体型、主毛色、左右不对称和辨识性大斑纹，不得再次根据通用审美重新设计角色。
- 视频运动过程中优先保持身份、主花色拓扑、左右归属和视觉连续性。毛发末端、被快速遮挡区域或极小斑纹允许出现短暂且不影响主人辨认的轻微生成波动；不得出现明显换脸、主毛色改变、大斑纹跨分区或左右互换、凭空增加显著斑纹、持续闪烁等严重错误。
- 每段视频的首帧和尾帧属于硬约束：必须准确匹配该动作绑定的 @front 或 @sleep，包括身份、表情、姿势、主花色、角色尺度、水平中心和地面基线。中间帧的轻微瑕疵不得传递到尾帧。
- 视频动作不得为了表现动作而主动展示 @front 与 @side 都没有记录的身体背面。若动作中短暂露出参考不足的区域，只能保持相邻基础毛色的连续延伸，不能补造辨识性花纹，也不能把已知花纹搬到该区域。

统一画布规范
- 画幅比例：16:9 横向；图片生成参数使用 2K，进入视频工作流前统一规范化为 1280×720。
- 宠物身体水平中心位于画面 x=50% 附近。
- 站立、坐姿或趴卧时，最低有效接触点位于画面高度约 86%（1280×720 画布约为 y=620）。
- 清醒坐姿整体高度约占画面高度 50%，四周保留安全空间，耳朵、四肢和尾巴完整可见。
- 姿势改变可以自然改变外接框的高宽，但头部、躯干和四肢的解剖尺度不得改变；不得为了填满画面自动放大。
- 动作需要更多空间时，减小动作幅度或增加留白，不得推拉镜头、缩放角色或裁切身体。


一、正面清醒身份母图（@front）

正向提示词

同时参考用户实际上传的 3～4 张合格照片，生成同一只真实 {{pet_type}} 的完整严格正面全身卡通形象。@photo1 与 @photo2 是正面姿态、正脸身份、胸口、前腿和正面花色的主要依据；两者信息冲突时按清晰度、完整度和遮挡程度逐分区选择，不得平均成另一张脸。@photo3 与可选的 @photo4 只用于补充体型、毛发、一侧花色、背部和尾巴，不得把正面姿态拉成三分之四角度。即使正面照片带有项圈或牵引链，也只移除附件，不得因此改用 45°照片的姿态。先逐张识别头部、左右耳、胸口、四肢、躯干两侧和尾巴，再按照“个体外观与花色锁定规范”逐分区还原。准确保留参考宠物最有辨识度的面部结构、头身比例、耳朵形状、眼睛颜色、鼻口形状、毛色、花纹、毛发长短、卷曲度与蓬松程度；尤其保持额头、眼周、口鼻、耳朵、胸口、背部、四肢和尾巴上每块可见花色的数量、形状、边界、相对位置和左右不对称。多张参考图信息冲突时，以该身体分区更清晰、角度更正、遮挡更少的一张为准，不得混合平均，不得混入其他动物特征，不得擅自增加衣服或饰品。

最终形象必须首先让主人认出“就是同一只宠物”，而不是只满足同品种、同毛色或相似风格。不得用常见品种模板替代个体脸型，不得为了更可爱而放大眼睛、缩短口鼻、圆化头部、统一耳朵或清除细小斑纹；皮克斯动画风格只能作用于渲染方式，不能重写真实宠物的个体外观。

正面姿态是硬约束：身体偏航角不超过 5°，鼻尖、两眼中点、胸骨中心与两只前爪之间的中点落在同一条垂直中心线上；头顶保持水平，头部不得歪斜或转向；两只眼睛处在同一水平高度，两侧肩膀透视大小一致，两条前腿完整、平行且都可见，两只前爪落在相同基线。允许真实左右花色不对称，但不允许用姿态不对称冒充真实花色差异。

背景为均匀纯绿色绿幕，精确色值 #00E676。背景只是无限纯色，不存在可见地面或地平线；脚掌下方也保持同一纯绿色，不生成接触阴影、暗带、倒影、环境遮蔽或颜色渐变。无杂物、无纹理，宠物毛发边缘不得出现绿色反光或溢色。

生成风格为皮克斯动画风格，精致三维卡通渲染，CG 质感，造型圆润自然，毛发柔软且有清晰层次，画面干净通透，色彩准确。宠物严格正面自然坐立，身体挺拔放松，头部保持端正且正视镜头，双眼明亮，神态亲切可爱，四肢和尾巴完整可见。

固定 16:9 横向构图。宠物水平居中，最低脚掌接触点位于画面高度约 86%，脚底至画面底边保留约 14% 空白；坐姿整体高度约占画面高度 50%。使用均匀正面柔光，不使用侧光、轮廓光、逆光或硬光。

反向提示词

改变物种、改变身份、套用品种模板、改变品种特征、改变毛色或花纹、斑纹镜像、左右互换、斑纹对称化、斑纹移动、斑纹合并、斑纹缺失、凭空增加斑纹、把多张照片平均混合、不同宠物特征混合、三分之四视角、45°视角、侧面视角、身体旋转、头部转向、歪头、鼻尖偏离胸骨中心、双眼高度不一致、两侧肩膀透视大小不一致、一条前腿遮挡另一条前腿、两只前爪基线不一致、脸型变化、眼睛颜色变化、口鼻缩短、眼睛夸张放大、身体比例失真、头部过大、身体过大、自动放大、裁切耳朵、裁切四肢、裁切尾巴、缺少肢体、多余肢体、多余尾巴、肢体粘连、五官扭曲、畸形爪子、衣服、饰品、项圈、道具、人物、其他动物、文字、标志、水印、可见地面、地平线、接触阴影、脚下暗带、环境遮蔽、阴影、倒影、背景杂物、背景纹理、背景渐变、绿色溢色、侧光、轮廓光、逆光、硬光、低画质、模糊、噪点。


二、单侧约 45° 清醒身份母图（@side）

正向提示词

同时参考用户实际上传的 3～4 张合格照片，并以刚生成或已确认的 @front 作为同一角色的身份、花色、材质和解剖尺度基准，生成同一只真实 {{pet_type}} 的完整单侧约 45° 清醒全身卡通形象。@photo3 是 45°姿态和该侧花色的主要依据；若存在 @photo4，则只在其角度更清晰或用于补充另一侧信息时采用。@photo1 与 @photo2 负责校正正脸身份和正面花色，不能让输出退回近似正面。选择 45°信息更清晰的一侧后，头部和躯干必须统一朝向同一侧。@front 负责锁定身份与尺度，对应方向的 45°实拍负责锁定姿态以及该侧躯干、四肢、背部和尾巴花色。必须与 @front 保持完全相同的脸型、头身比例、耳朵、眼睛、鼻口、毛发材质、基础毛色和卡通渲染风格。

@side 不是新角色，也不是把 @front 简单水平翻转。严格保留真实宠物的左右不对称：只能显示所选方向真实存在的斑纹，不能把另一侧花纹镜像过来。多张照片信息冲突时，以该身体分区更清晰、角度更正、遮挡更少的实拍照片为准；未被实拍记录的区域只延伸相邻基础毛色，不补造辨识性斑块。

45°姿态是硬约束：头部和躯干相对镜头统一旋转约 35°～50°，既能看清双眼和主要正脸特征，也能完整展示所选一侧的肩部、躯干、前后腿与尾巴花色。近侧眼睛、耳朵、肩膀和前腿在透视上略大，远侧对应部位仍可见但略小；鼻尖明确偏向所选一侧，不得仍落在胸骨正中。禁止接近正面的 0°～15°姿态，也禁止超过 70°的纯侧面或回头姿态。宠物保持与 @front 相同的自然坐姿和清醒表情，四肢数量与结构正确，尾巴完整可见；不穿衣服，不佩戴项圈或饰品，不出现任何道具。

背景为均匀纯绿色绿幕，精确色值 #00E676。背景只是无限纯色，不存在可见地面或地平线；脚掌下方也保持同一纯绿色，不生成接触阴影、暗带、倒影、环境遮蔽或颜色渐变。无杂物、无纹理，毛发边缘不得出现绿色反光或溢色。沿用 @front 的同一固定 16:9 画布、相机高度、焦距、角色解剖尺度、水平中心、地面基线和均匀正面柔光；最低脚掌接触点位于画面高度约 86%，不得因为转身自动放大或缩小。

反向提示词

不同角色、重新设计角色、简单翻转 @front、完全复制 @front 正面姿态、左右花纹互换、斑纹镜像、花纹平均混合、改变脸型、改变头身比例、改变毛色、改变毛发材质、改变耳朵或尾巴、改变眼鼻口特征、严格正面姿势、旋转不足 15°、严格 90°纯侧面、旋转超过 70°、完全背对镜头、头部与躯干方向不一致、头部回看镜头、只显示一只眼睛、胸口完全正对镜头、自动放大、自动缩小、镜头变化、位置跳变、裁切耳朵、裁切四肢、裁切尾巴、缺少肢体、多余肢体、多余尾巴、衣服、饰品、项圈、道具、人物、其他动物、文字、标志、水印、可见地面、地平线、接触阴影、脚下暗带、环境遮蔽、阴影、倒影、背景杂物、背景纹理、背景渐变、绿色溢色、侧光、轮廓光、逆光、硬光、低画质、模糊、噪点。


三、睡姿母图（@sleep）

正向提示词

同时参考用户已确认的 @front 与 @side，以两张清醒身份母图共同定义的造型、外观、花色与比例生成完全相同的 {{pet_type}} 睡着时的完整全身图。睡姿母图不得回到通用品种模板，也不得绕过已确认母图重新解释 @photo1～@photo4。严格保持 @front 的正面身份和整体尺度，并使用 @side 补足睡姿朝向所显示的侧面体型、四肢、背部、尾巴和花色，不重新设计角色。

睡姿变化只允许 @front 与 @side 中已确认的花色随身体表面发生连续的姿态和透视变形。每块可见斑纹必须保持原来的身体分区、左右方向、数量、形状关系和相对身体地标位置，不能迁移、镜像、复制、删减、变色或补造。侧躺方向应与 @side 的方向一致，使已确认的侧面花色直接可见；不得为了睡姿主动翻到两张母图都未记录的一侧。若局部确实因姿势露出但两张母图均未提供该区域外观，只能自然延伸邻近的基础毛色，禁止新增任何辨识性斑块。

宠物自然侧躺并舒适蜷睡，双眼自然闭合，四肢放松收拢；参考图中能看到尾巴时，让尾巴自然绕在身体旁，不能凭空增加或改变尾巴。姿态安静、可爱，呼吸放松。

沿用 @front 与 @side 的同一台固定相机、同一焦距、同一 16:9 画布、同一角色解剖尺度和同一光照。最低身体接触点仍位于画面高度约 86%，身体水平中心保持在 x=50% 附近。睡姿会自然变矮、变宽，但头部像素尺度和躯干长度尺度必须与两张清醒母图一致；绝对不要因为睡姿较矮而放大宠物填满画面。
