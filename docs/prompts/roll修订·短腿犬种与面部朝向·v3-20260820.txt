# roll 动作提示词修订 v3（2026-08-20）

## 为什么改

roll 是七个动作里唯一长期不达标的：通过率 42%，其余动作 85–90%。逐帧重新打分后原因很清楚——旧提示词把 1.5s–4.5s 整整三秒安排成「四脚朝天 / 仰面」，占全片一半。狗一旦完全翻到背面，脸就离开镜头，面部相似度在那些帧上塌掉。

质检判据已经改成「低于严重分数线的帧占比」，上限 8%。已交付的 roll 落在 0–3.9%，而失败那三条是 13.7%–25.5%——全部来自仰面段。

短腿长身犬种（柯基、腊肠、巴吉度）更严重：模型为了把「四爪朝天」画好看，会不自觉地把腿拉长、把头身比例改掉，两头都丢分。

## 改了什么

1. 仰面时间从三秒压到不足一秒，其余时间保持侧躺。
2. 新增硬约束：**全程脸朝镜头**，侧躺和仰卧时头也要向镜头方向偏。
3. 新增体型条款：短腿长身犬种翻滚时腿依然是短的，不许为了动作好看拉长四肢或改头身比例。
4. 反向提示词补上：脸转开、脸被遮、头埋地、拉长四肢、改变腿长与头身比例。

猫版做同样的结构调整，去掉犬种条款。
