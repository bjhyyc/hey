# Electron 桌宠客户端需求文档

## 1. 文档信息

- 产品名称：桌宠客户端
- 当前版本：MVP 客户端完整功能版
- 技术方向：Electron + HTML/CSS/JavaScript
- 目标平台：macOS、Windows
- 文档目标：先定义一个离线可用、素材包标准稳定、可后续接入官网/后台交付的桌宠客户端。

> 当前实现校准：本文保留产品需求和早期 MVP 语境，其中部分“状态页 / 动作页 / states manifest”描述已经被当前实现替换。当前代码事实以 `assets -> animations -> triggerRules -> inline actions` 为准，manifest 使用 `schemaVersion`、`packageId`、`animations.default`、`animations.clips` 和 `triggerRules`。最新架构见 [../architecture/current-architecture.md](../architecture/current-architecture.md)，制作格式见 [../USER_GUIDE.md](../USER_GUIDE.md)。

## 2. 产品定位

桌宠客户端是一款运行在用户电脑桌面的透明悬浮宠物应用。用户可以导入自己制作或由平台交付的动态素材，让任意形象、IP、角色成为可拖拽、可互动、可配置的桌宠。

第一版优先保证客户端完整体验，不依赖后端也能正常使用。官网、支付、订单、后台交付在后续版本围绕客户端素材包标准扩展。

## 3. 目标用户

### 3.1 普通用户

- 希望在电脑桌面放置个性化宠物、角色、虚拟形象。
- 可以直接使用平台交付的素材包，不需要理解复杂制作流程。
- 需要简单完成导入、切换、调整大小、拖动位置、隐藏和退出。

### 3.2 创作者/运营用户

- 希望把已有视频、GIF、角色形象制作成桌宠素材。
- 需要验证素材是否透明、是否适配状态、动作和触发规则，是否可以打包交付。
- 需要导出标准素材包，方便分发给其他用户。

## 4. 产品目标

### 4.1 MVP 目标

1. 提供 macOS 和 Windows 可运行的 Electron 桌宠客户端。
2. 支持透明、无边框、置顶的桌宠展示窗口。
3. 支持用户导入动态素材并绑定不同桌宠状态或自定义动作。
4. 支持内置触发条件列表，例如点击、拖动、鼠标移动、鼠标进入、鼠标离开、定时、随机等。
5. 支持用户通过单选、多选、OR、AND 组合触发条件，并配置命中后执行的动作。
6. 支持控制面板管理素材、状态、动作、触发规则、文案、显示和系统设置。
7. 支持标准素材包一键导入和导出，为后续后台交付做准备。
8. 支持配置本地保存，修改后实时生效，无需重启。

### 4.2 暂不作为 MVP 核心目标

- 用户登录、账号体系。
- 在线素材商城。
- 在线支付。
- 后台订单管理。
- 云端素材同步。
- AI 自动生成素材。

这些能力放入后续产品阶段，但第一版客户端需要提前定义素材包格式，保证后续可平滑接入。

## 5. 核心用户流程

### 5.1 首次使用流程

1. 用户安装并打开客户端。
2. 客户端展示默认桌宠或引导用户导入素材。
3. 用户进入控制面板，选择导入素材或导入素材包。
4. 系统校验素材格式，生成预览。
5. 用户将素材绑定到待机、点击、拖拽等状态，或新增为自定义动作。
6. 用户选择一个或多个触发条件，并设置 OR/AND 关系。
7. 用户选择触发后执行的动作。
8. 桌宠主窗口实时展示效果。
9. 用户调整尺寸、位置、置顶、穿透等设置。
10. 设置自动保存。

### 5.2 普通互动流程

1. 用户点击桌宠。
2. 桌宠随机播放一个点击状态动作。
3. 桌宠显示一条随机文案气泡。
4. 动作结束后回到待机状态。

### 5.3 拖拽流程

1. 用户按住桌宠拖动。
2. 桌宠进入拖拽状态。
3. 用户松开后保存新位置。
4. 桌宠回到待机状态。

### 5.4 自定义触发规则流程

1. 用户进入控制面板的“触发规则”页面。
2. 点击“新增规则”。
3. 用户从软件内置触发条件列表中选择条件。
4. 用户选择单个条件，或多选条件并设置条件关系为 OR 或 AND。
5. 用户选择规则触发后执行的动作，例如播放动作、显示文案、切换状态、调整大小、隐藏桌宠。
6. 用户保存规则。
7. 系统立即启用规则，并在桌宠主窗口中按配置响应。

### 5.5 素材包导入流程

1. 用户点击“导入素材包”。
2. 选择 `.petpack` 文件。
3. 系统解包并校验 `manifest.json`。
4. 展示素材包名称、预览图、包含的状态、动作、触发规则和文案。
5. 用户确认导入。
6. 系统复制素材到本地用户数据目录。
7. 桌宠切换到新素材包。

### 5.6 素材包导出流程

1. 用户在控制面板选择当前桌宠配置。
2. 点击“导出素材包”。
3. 系统打包素材、配置、状态映射、自定义动作、触发规则、互动文案和预览图。
4. 生成 `.petpack` 文件。
5. 用户可保存或发送给其他用户。

## 6. 客户端窗口设计

### 6.1 桌宠主窗口

桌宠主窗口是透明无边框悬浮窗口，只展示桌宠本体和必要的轻量互动元素。

功能要求：

- 背景透明，无系统窗口边框。
- 默认置顶显示。
- 支持拖拽移动。
- 支持鼠标穿透开关。
- 支持点击触发互动。
- 支持悬停时显示快捷按钮。
- 支持右键菜单。
- 支持按比例缩放桌宠。
- 支持记录最后位置。

快捷按钮建议：

- 设置。
- 隐藏。
- 切换状态。
- 锁定/解锁拖动。

### 6.2 控制面板窗口

控制面板用于管理桌宠、素材、状态、动作、触发规则、文案和系统设置。

建议页面：

1. 概览页：当前桌宠、状态/动作/规则数量、素材包信息、快速操作。
2. 素材页：上传、预览、删除、替换素材。
3. 状态页：绑定待机、点击、拖拽、随机、定时、休息等基础状态。
4. 动作页：新增、编辑、删除用户自定义动作，并绑定素材、文案和执行参数。
5. 触发规则页：选择内置触发条件，配置触发参数过滤、单选、多选、OR、AND 关系，以及触发后的动作。
6. 互动页：配置点击文案、随机文案、气泡样式、互动按钮。
7. 显示页：配置尺寸、透明度、置顶、穿透、位置重置。
8. 系统页：开机启动、托盘、日志、导入导出、恢复默认。

### 6.3 素材导入向导

素材导入向导用于降低普通用户导入素材的失败率。

导入步骤：

1. 选择文件。
2. 格式校验。
3. 透明效果预览。
4. 绑定桌宠状态或自定义动作。
5. 保存并应用。

校验内容：

- 文件格式是否支持。
- 文件是否可读取。
- 视频是否可播放。
- 是否存在透明通道。
- 文件体积是否超过限制。
- 分辨率是否明显过大。

### 6.4 托盘菜单

客户端应提供系统托盘入口。

菜单项：

- 显示/隐藏桌宠。
- 打开控制面板。
- 切换当前状态。
- 锁定/解锁拖动。
- 鼠标穿透开关。
- 退出应用。

## 7. 触发条件与动作系统

第一版需要支持较高程度的定制化。客户端内置可监听的触发条件，用户可以基于这些条件创建规则；规则命中后执行一个或多个动作。桌宠状态仍然存在，但它是动作系统中的一种执行结果。

### 7.1 核心概念

- 触发条件：软件内置的事件来源，例如点击、拖动、鼠标移动、鼠标进入。
- 触发参数：触发条件发生时携带的上下文数据，例如鼠标坐标、是否在桌宠区域内、与桌宠距离。
- 条件关系：多个触发条件之间的组合关系，支持 OR 和 AND。
- 参数过滤：对触发参数做进一步判断，例如距离小于 80px、鼠标在桌宠内部、移动速度超过指定值。
- 触发规则：由触发条件、触发参数过滤、条件关系、限制参数和执行动作组成。
- 动作：规则命中后执行的结果，可以是内置动作，也可以是用户新增动作。
- 状态：桌宠当前正在展示的行为状态，例如 idle、drag、sleep。

### 7.2 内置触发条件

MVP 内置触发条件列表：

- click：点击桌宠。
- doubleClick：双击桌宠。
- rightClick：右键点击桌宠。
- dragStart：开始拖动。
- dragging：拖动中。
- dragEnd：拖动结束。
- mouseEnter：鼠标进入桌宠区域。
- mouseLeave：鼠标离开桌宠区域。
- mouseMove：鼠标移动，可携带是否在桌宠区域内、与桌宠距离、移动速度和方向等参数。
- hoverDuration：鼠标悬停达到指定时长。
- idleDuration：用户无互动达到指定时长。
- timer：固定时间或周期触发。
- randomTimer：随机间隔触发。
- appLaunch：客户端启动后触发。
- packageLoaded：素材包加载完成后触发。

后续可扩展触发条件：

- keyboardShortcut：键盘快捷键。
- screenEdge：桌宠接近屏幕边缘。
- batteryState：设备电量状态变化。
- networkState：网络状态变化。
- systemTimeRange：处于指定时间段。

### 7.3 触发事件参数

部分触发条件发生时，需要携带参数。规则编辑器应允许用户基于参数继续筛选，避免只要发生事件就触发动作。

通用参数：

- timestamp：事件发生时间。
- eventSource：事件来源，例如 petWindow、globalMouse、timer。
- petPosition：桌宠窗口在屏幕中的位置，包含 x、y、width、height。
- mousePosition：鼠标在屏幕中的位置，包含 x、y。
- mouseLocalPosition：鼠标在桌宠窗口内的相对位置，包含 x、y。
- isInsidePet：鼠标是否在桌宠窗口范围内。
- distanceToPetCenter：鼠标到桌宠中心点的距离，单位 px。
- distanceToPetBounds：鼠标到桌宠边界的最短距离，单位 px；在桌宠内部时可为 0。
- screenPosition：桌宠所在屏幕信息，包含屏幕宽高和可用区域。

鼠标移动类参数：

- deltaX：本次鼠标移动的 x 轴变化量。
- deltaY：本次鼠标移动的 y 轴变化量。
- speed：鼠标移动速度，单位 px/s。
- direction：移动方向，例如 left、right、up、down、none。
- isMovingTowardPet：鼠标是否正在靠近桌宠中心。
- isMovingAwayFromPet：鼠标是否正在远离桌宠中心。

拖拽类参数：

- dragStartPosition：拖拽开始时桌宠位置。
- currentPosition：拖拽中的桌宠位置。
- dragDeltaX：桌宠拖动的 x 轴变化量。
- dragDeltaY：桌宠拖动的 y 轴变化量。
- dragDistance：本次拖拽累计距离。
- dragDurationMs：本次拖拽持续时间。

时间类参数：

- elapsedMs：达到指定状态或无互动状态的持续时间。
- currentTime：当前时间。
- currentHour：当前小时。
- dayOfWeek：当前星期。

### 7.4 参数过滤规则

参数过滤用于判断触发条件是否真正满足。每个触发条件可以配置 0 个或多个参数过滤项。

过滤项包含：

- 参数名，例如 distanceToPetCenter。
- 运算符，例如 `=`, `!=`, `>`, `>=`, `<`, `<=`, `between`, `in`, `notIn`。
- 参数值，例如 80、true、left。
- 单位，例如 px、ms、s。

示例：

- mouseMove 发生，并且 isInsidePet = true。
- mouseMove 发生，并且 distanceToPetCenter <= 100px。
- mouseMove 发生，并且 isMovingTowardPet = true，speed >= 300px/s。
- idleDuration 发生，并且 elapsedMs >= 60000ms。
- dragging 发生，并且 dragDistance >= 200px。

同一个触发条件内部的多个参数过滤项默认按 AND 处理。后续可以扩展为参数过滤项组，支持更复杂的 OR/AND 嵌套。

### 7.5 条件选择方式

每条规则支持以下选择方式：

- 单选：选择一个触发条件，命中后执行动作。
- 多选 OR：选择多个触发条件，任意一个命中即执行动作。
- 多选 AND：选择多个触发条件，需要在指定时间窗口内全部满足才执行动作。

AND 关系需要支持时间窗口配置。例如用户配置“鼠标进入 AND 点击”，时间窗口为 3 秒，则用户必须先让鼠标进入桌宠区域，并在 3 秒内点击桌宠，规则才触发。

条件命中需要同时满足触发条件和该条件下的参数过滤。例如用户选择 mouseMove，并设置 distanceToPetCenter <= 80px，则只有鼠标移动且距离桌宠中心不超过 80px 时才算命中。

### 7.6 触发规则参数

每条规则可配置：

- 规则名称。
- 是否启用。
- 触发条件列表。
- 每个触发条件的参数过滤项。
- 条件关系：single、or、and。
- AND 时间窗口。
- 冷却时间，避免短时间重复触发。
- 每次命中后执行一个动作或动作序列。
- 动作执行策略：顺序执行、随机选一个执行。
- 优先级。
- 是否打断当前动作。
- 执行后是否回到 idle。

### 7.7 内置动作示例

当前实现内置动作：

- blank：占位动作，可用于动作序列中的等待。
- playAnimation：播放指定动画剪辑。
- setKeyframeProgress：设置关键帧动画进度。
- showMessage：显示一条文案气泡。
- randomMessage：随机显示一条文案气泡。
- changeScale：调整桌宠大小。
- changeOpacity：调整透明度。
- movePet：移动桌宠窗口。
- pomodoroTimer：启动或控制番茄钟运行时。
- hidePet：隐藏桌宠。
- showPet：显示桌宠。
- resetPosition：回到默认位置。
- openPanel：打开控制面板。

### 7.8 用户自定义动作

用户可以新增自定义动作，第一版的自定义动作不执行脚本，只通过可视化表单组合安全能力。

自定义动作可包含：

- 动作名称。
- 绑定素材。
- 播放方式：循环、播放一次、播放指定时长。
- 播放结束后的状态。
- 绑定文案。
- 文案展示时长。
- 是否允许被更高优先级动作打断。
- 动作权重，用于随机选择。

不允许用户在动作中编写或执行任意 JavaScript，以避免素材包带来安全风险。

### 7.9 基础状态类型

客户端仍需内置以下基础状态，便于普通用户快速配置：

- idle：待机状态，默认循环播放。
- click：点击状态，用户点击后播放。
- drag：拖拽状态，用户拖动时播放。
- hover：悬停状态，鼠标停留时播放。
- random：随机状态，按时间间隔随机触发。
- timed：定时状态，在指定时间或周期触发。
- sleep：休息/隐藏状态，可降低存在感。

这些状态可被系统默认规则触发，也可以被用户自定义规则触发。

### 7.10 默认规则

为了让普通用户导入素材后立即可用，客户端需要为基础状态生成默认规则：

- click 触发 click 状态动作。
- dragStart 或 dragging 触发 drag 状态动作。
- mouseEnter 触发 hover 状态动作。
- randomTimer 触发 random 状态动作。
- timer 触发 timed 状态动作。
- idleDuration 触发 sleep 状态动作。

用户可以禁用、编辑或删除默认规则。

### 7.11 状态与动作优先级

当多个规则同时触发时，按以下顺序决策：

1. 优先级数值更高的规则先执行。
2. 同优先级时，dragging 类规则优先。
3. 如果当前动作不允许被打断，新规则进入等待或被忽略。
4. 如果当前动作允许被打断，新规则立即执行。
5. 没有可执行规则时回到 idle。

### 7.12 播放规则

- idle 默认循环播放。
- playAnimation 可配置循环、播放一次或指定时长。
- click 类动作默认播放一次后回到 idle。
- drag 类动作在拖动期间循环播放，松开后回到 idle。
- random 类动作播放一次后回到 idle。
- timed 可配置播放一次或循环一段时间。
- sleep 可展示静态或低频动画。

## 8. 素材支持与规范

### 8.1 支持格式

第一版支持：

- GIF
- WebP
- WebM
- MP4
- MOV
- PNG 静态图

推荐格式：

- 透明动态素材优先使用 WebM 或带 Alpha 通道的 MP4/MOV。
- 简单动画可使用 GIF 或 WebP。
- 静态状态可使用 PNG。

### 8.2 素材建议规格

- 推荐分辨率：512 x 512 至 1024 x 1024。
- 单个文件建议不超过 50 MB。
- 素材主体应居中，边缘留有透明区域。
- 动作首尾应尽量自然衔接。
- 点击、随机、定时动作建议时长 1-5 秒。
- 待机动作建议可循环播放。

### 8.3 素材制作参考流程

参考用户提供的制作流程，平台后续可在官网教程中说明：

1. 明确桌宠需求和角色形象。
2. 生成或准备角色动态素材。
3. 使用视频工具处理透明背景。
4. 导出透明动态视频或动图。
5. 导入客户端并绑定状态、动作或触发规则。
6. 通过客户端导出标准素材包。

## 9. 素材包标准

### 9.1 文件格式

素材包扩展名：`.petpack`

本质可以采用 zip 压缩包结构，便于跨平台处理。

### 9.2 推荐目录结构

```text
example.petpack
├── manifest.json
├── preview.png
├── assets/
│   ├── idle.webm
│   ├── click_01.webm
│   ├── drag.webm
│   └── follow.webm
```

### 9.3 manifest.json 字段

```json
{
  "schemaVersion": 1,
  "packageId": "cute-dog-001",
  "name": "可爱小狗",
```

### 9.4 导入校验规则

- 必须存在 `manifest.json`。
- `schemaVersion` 必须兼容当前客户端。
- `packageId`、`name`、`version` 必填。
- 必须包含 `animations.default` 和 `animations.clips`。
- manifest 中引用的素材文件必须存在。
- `actions` 中引用的素材、状态和文案必须存在或可直接读取。
- `triggers` 中的条件必须来自客户端支持的内置触发条件列表。
- `triggers.conditions` 可以使用字符串简写，也可以使用带 `type` 和 `filters` 的对象结构；导出时推荐统一使用对象结构。
- `filters` 中的字段必须来自对应触发条件支持的参数白名单。
- `filters` 中的运算符必须来自客户端支持的运算符列表。
- `triggers` 中的 `relation` 仅支持 `single`、`or`、`and`。
- `triggers` 中引用的动作 ID 必须存在。
- 不支持的文件格式需要提示用户。
- 解包后不得允许路径穿越写入。

## 10. 配置系统

### 10.1 本地保存内容

客户端需保存以下配置：

- 当前启用的素材包。
- 桌宠位置。
- 桌宠缩放比例。
- 透明度。
- 是否置顶。
- 是否鼠标穿透。
- 是否开机启动。
- 是否显示悬停按钮。
- 当前语言。
- 文案配置。
- 状态配置。
- 用户自定义动作配置。
- 触发规则配置。
- 规则优先级、冷却时间和 AND 时间窗口配置。
- 触发条件参数过滤配置。

### 10.2 保存方式

- 配置存储在 Electron 用户数据目录。
- 使用 JSON 文件保存。
- 修改设置后实时写入。
- 写入失败时给出提示并保留当前内存状态。

### 10.3 推荐文件结构

```text
userData/

│       ├── manifest.json
│       ├── preview.png
│       └── assets/
└── logs/
    └── app.log
```

## 11. 交互文案与气泡

### 11.1 文案类型

- 点击文案。
- 随机闲聊文案。
- 定时提醒文案。
- 导入成功文案。
- 错误提示文案。
- 自定义动作文案。

### 11.2 气泡要求

- 气泡显示在桌宠附近。
- 不应遮挡桌宠主体。
- 支持自动消失。
- 支持最大宽度和换行。
- 支持用户关闭文案气泡。

### 11.3 文案与动作绑定

- 文案可以独立配置，也可以绑定到自定义动作。
- 一个动作可以绑定一条固定文案或一个文案池。
- 当规则触发动作序列时，文案可以跟随动作顺序展示。
- 当规则触发随机动作时，文案可以随被选中的动作一起展示。

## 13. 异常与提示

### 13.1 素材导入失败

常见原因：

- 文件格式不支持。
- 文件损坏或无法读取。
- 视频无法播放。
- 素材包 manifest 缺失。
- 素材包字段不合法。

处理方式：

- 显示明确错误原因。
- 不写入不完整素材。
- 保留用户当前桌宠配置。

### 13.2 运行异常

常见场景：

- 素材播放失败。
- 配置读取失败。
- 配置写入失败。
- 素材文件被用户删除。

处理方式：

- 回退到默认桌宠或默认状态。
- 写入日志。
- 在控制面板显示修复建议。

## 14. 非功能需求

### 14.1 性能

- 桌宠常驻时 CPU 占用应保持较低。
- 待机状态不应造成明显风扇或卡顿。
- 大素材导入时应显示进度。
- 控制面板打开不应影响桌宠动画播放。
- mouseMove、dragging 等高频触发条件需要节流或合帧处理。
- 高频触发参数计算不得阻塞桌宠动画播放。

### 14.2 稳定性

- 主窗口崩溃后应用可重新创建窗口。
- 配置文件损坏时可使用默认配置恢复。
- 导入素材包失败不得破坏已有素材包。

### 14.3 安全性

- 素材包解压必须防止路径穿越。
- 不执行素材包内的脚本。
- 用户自定义动作只能使用客户端提供的安全动作类型，不允许执行任意代码。
- 不允许素材包覆盖客户端程序文件。
- 本地日志不记录用户敏感路径以外的信息。

### 14.4 易用性

- 默认提供一个可运行的示例桌宠。
- 空状态需要引导用户导入素材。
- 重要设置需要即时预览。
- 触发规则编辑器需要提供内置模板，避免普通用户必须从零配置。
- 条件关系 OR/AND 需要用清晰的可视化控件展示。
- 参数过滤需要根据字段类型展示对应控件，例如数字输入、范围输入、布尔开关、枚举下拉。
- 危险操作需要二次确认，例如删除素材包。

## 15. 验收标准

### 15.1 基础运行

- macOS 可安装并启动。
- Windows 可安装并启动。
- 桌宠窗口透明、无边框、可置顶。
- 桌宠可拖动，重启后位置保持。

### 15.2 素材管理

- 可导入 GIF、WebP、WebM、MP4、MOV、PNG。
- 可预览导入素材。
- 可删除素材。
- 可把素材绑定到不同状态或自定义动作。
- 不支持格式会给出明确提示。

### 15.3 状态互动

- 待机状态可循环播放。
- 点击桌宠可触发点击动作和文案。
- 拖拽桌宠可触发拖拽状态。
- 随机动作可按配置间隔触发。
- 状态播放结束后能回到待机状态。

### 15.4 触发规则与自定义动作

- 控制面板可以展示内置触发条件列表。
- 用户可以新增、编辑、启用、禁用、删除触发规则。
- 用户可以为规则选择单个触发条件。
- 用户可以为规则选择多个触发条件，并设置 OR 关系。
- 用户可以为规则选择多个触发条件，并设置 AND 关系和时间窗口。
- 用户可以查看每个触发条件携带的参数说明。
- 用户可以为触发条件增加参数过滤，例如距离、坐标、是否在桌宠内、速度、方向。
- mouseMove 触发条件可以基于鼠标坐标、是否在桌宠内部、与桌宠距离、移动速度和移动方向进行过滤。
- dragging 触发条件可以基于拖拽距离、拖拽时长和位移方向进行过滤。
- 用户可以新增自定义动作并绑定素材、文案和播放方式。
- 规则触发后可以执行单个动作、顺序动作或随机动作。
- 规则冷却时间生效，避免连续重复触发。
- 规则优先级生效，高优先级动作可以按配置打断低优先级动作。
- 导出的 `.petpack` 可以保留自定义动作和触发规则。

### 15.5 控制面板

- 可打开和关闭控制面板。
- 可调整桌宠大小、透明度、置顶、穿透。
- 修改后实时生效。
- 配置重启后保持。

### 15.6 素材包

- 可导入合法 `.petpack`。
- 可拒绝非法 `.petpack` 并提示原因。
- 可导出当前桌宠为 `.petpack`。
- 导出的素材包可被同客户端再次导入。

## 18. 开放问题
